# Raid Check v1.0.0

RimWorld 1.7用の襲撃編成チェックMODの初の正式リリースです。

- 現在の襲撃ポイントと選択した派閥・戦術・侵入方法に基づく編成例を、手動で試算します。
- 複数派閥の比較、敵種別の集計、編成例の表示、CSV出力に対応しています。
- 通常襲撃のほか、工兵・破壊・包囲や降下など、ゲーム側の条件を満たす組み合わせを扱います。
- 通常プレイ中に定期的な襲撃試算は行いません。

## インストール

配布ZIPを展開し、内部の `RaidCheck` フォルダーを RimWorld の `Mods` フォルダーに入れて有効化し、ゲームを再起動してください。Harmonyは不要です。

## 制限・検証状況

編成は条件を指定した試算例であり、次の襲撃の予告ではありません。特殊な独自Worker、クエスト固定部隊、虫・アノマリー特殊部隊、メカクラスターの建物や装備などは対象外です。

参照DLLを用いたビルドと自動テストを行っています。実ゲームのAPI・画面・保存状態・性能は未検証です。[検証記録](https://github.com/pengin0503/rimworld-raid-check/blob/main/docs/validation.md)も参照してください。
